# Python で値が静かに誤るパターン

例外を出さずに誤った結果を返すパターン。症状に心当たりがあれば、該当する書き方を grep で探す。

| 症状 | 疑う書き方 | 確かめ方 / 直し方 |
| --- | --- | --- |
| 2 回目以降の呼び出しだけ結果が違う、テストの順序で結果が変わる | 可変な既定引数 `def f(x, seen=[])`、`={}` | 既定値を `None` にして関数の中で作る |
| 件数やページ数が 1 足りない | `//` による切り捨て | 端数のある件数で試す。`-(-n // size)` か `math.ceil` |
| 実行のたびに順序が変わる | `list(set(...))`、`set` の反復 | `PYTHONHASHSEED` を変えて比べる。順序を保つなら `list(dict.fromkeys(xs))` |
| 数値の並びが 9, 10, 100 ではなく 10, 100, 9 になる | 文字列のまま比較・ソート | 読み込み時に `int` / `Decimal` に変換する |
| `"None"` という文字列が出力に出る | `None` を f-string や `str()` に通している | 値が `None` になる経路を遡る |
| 設定の一部だけ既定値が消える | `{**default, **override}` や `dict.update` で `None` が上書きする | マージ時に `None` を飛ばすか、明示的な削除と区別する |
| ループで作った関数が全部同じ値を使う | クロージャの遅延束縛 `lambda: i` | `lambda i=i: i` か `functools.partial` |
| 0.1 + 0.2 のような誤差、金額の 1 円ずれ | `float` での金額計算、`round` の偶数丸め | `Decimal` と明示した丸めを使う |
| 日時が 9 時間ずれる、比較で例外 | naive と aware の混在、`datetime.now()` と `utcnow()` | タイムゾーンを持たせて統一する |
| 同じ内容なのに一致しない | `is` で値を比較 | `==` で比べる |
| 空のときだけ誤る | `if x:` が 0、空文字、空リストを偽とみなす | `if x is None:` と区別する |
| 一部の要素が処理されない | 反復中のリストや辞書の変更 | コピーを反復する |
| 例外が出ないのに処理されていない | `except Exception: pass`、広い `except` | 握りつぶした例外をログに出す |
| 変更が呼び出し元に漏れる | 引数のリスト・辞書をその場で書き換える | コピーしてから変更する |

同じ書き方は、一か所見つかれば近くにもあることが多い。修正の前に `rg` などでリポジトリ全体を探す。
